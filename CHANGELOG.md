# Changelog

## 2.0.5

Needs AC:Unreal client v146 or newer.

- Alerts show the matching line in the chat window you choose, in the alert color. The original line stays where it is.
- Alerts check players' chat and server messages. Trade, LFG, Roleplay, Society, Olthoi, NPCs and vendors are not checked.
- Match: All words (default), Whole words or Exact line. Any part is removed.
- Alerts play a sound, with on/off and volume.
- The Alert list shows the whole chat line.
- Quest flag is a search box.
- Alert buttons: C (Chat), E (Edit), X (Remove).
- The starting quest alerts are off.
- New filters: Death messages, NPC tells and Vendor tells.
- Every filter box can be ticked at once.
- Filters on and Alerts on switches.
- Only game lines are filtered, never a player's chat.
- The plugin only receives the lines it needs, so busy chat doesn't slow it down.
